FreelancersOS Recap — Vercel

Option A (drag & drop): vercel.com → Add New → Project → "Deploy" by dragging this whole folder.
Option B (CLI): inside this folder run `npx vercel --prod`.

No build step. Framework preset: "Other". Output directory: the folder root.
After deploy, add your domain (freelancersos.com) under Project → Settings → Domains.
Keep index.html, support.js and assets/ together.
